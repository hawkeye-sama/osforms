OSForms is a form backend that stores submissions and routes them to your own integrations: Resend, Google Sheets, and webhooks. It's free because you bring your own API keys.

## Why OSForms

Many form backends (Formspree, FormBold, Basin) put integrations behind paid plans, even though your own API keys power them. OSForms includes **every integration on the free plan, with 100 submissions/month**.

## How it works

1. Create a form in your dashboard and get a unique endpoint URL
2. Point your HTML form at the endpoint
3. Configure integrations with your own API keys
4. Submissions are stored, and integrations run in the background

```html
<form action="https://osforms.com/api/v1/f/your-form-slug" method="POST">
  <input type="text" name="name" placeholder="Your name" />
  <input type="email" name="email" placeholder="Your email" />
  <textarea name="message" placeholder="Your message"></textarea>
  <button type="submit">Send</button>
</form>
```

No JavaScript required. Works with any HTML form.

## Key features

- **Any HTML form**: post `urlencoded`, `multipart`, or JSON to your endpoint
- **3 integrations**: Resend email (with auto-reply), Google Sheets, signed webhooks
- **Pull API**: read submissions server to server with scoped, read-only API keys
- **React SDK**: conversational (Typeform-style) and classic forms with 12 field types and conditional logic
- **Spam protection**: honeypot field, Google reCAPTCHA, hCaptcha
- **CORS control**: per-form origin allowlist
- **Rate limiting**: per form, per IP
- **CSV export** of all submissions

File uploads are accepted but not stored. See [Submit a Form](/docs/api-reference/submit-form#files).

## Pricing

| Plan | Submissions | Integrations |

Paid plans with higher limits are coming. OSForms is [open source](https://github.com/hawkeye-sama/osforms), so you can also self-host it.

No per-integration fees. You pay your own providers (for example Resend) directly.
