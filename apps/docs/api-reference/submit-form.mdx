The public submission endpoint. No authentication required.

## Endpoint

```
POST https://osforms.com/api/v1/f/{slug}
```

`{slug}` is the 12-character ID at the end of your form's endpoint URL, shown in the **Setup** tab of the form.

Accepts `application/json`, `application/x-www-form-urlencoded`, and `multipart/form-data`.

## HTML form usage

```html
<form action="https://osforms.com/api/v1/f/{slug}" method="POST">
  <input type="text" name="name" />
  <input type="email" name="email" />
  <button type="submit">Send</button>
</form>
```

Each input's `name` becomes a key in the stored submission. Repeated names (for example a group of checkboxes) are stored as an array.

If the form has a **Redirect URL** set, the browser gets a `303` redirect there. Without one, the endpoint answers with the JSON below, so set a redirect URL for plain HTML forms.

## API / JSON usage

```bash
curl -X POST https://osforms.com/api/v1/f/{slug} \
  -H "Content-Type: application/json" \
  -d '{"name": "Jane", "email": "jane@example.com"}'
```

```json
{ "success": true, "message": "Submission received" }
```

Requests sent as JSON (or with `Accept: application/json`) always get JSON back, even when a redirect URL is set.

## Response codes

| Status | Meaning                                                                  |
| ------ | ------------------------------------------------------------------------ |
| `200`  | Submission stored (JSON response)                                        |
| `303`  | Submission stored, redirecting to the form's redirect URL                |
| `400`  | Body couldn't be parsed, or CAPTCHA token missing or failed verification |
| `403`  | Origin not in the form's allowed origins, or monthly limit reached       |
| `404`  | No active form with this slug                                            |
| `429`  | Rate limit exceeded                                                      |

Errors return `{ "error": "<message>" }`.

## Files

Multipart uploads are accepted, but **files are not stored**. A file field is saved as a placeholder string such as `[File: resume.pdf, 48213 bytes]`. If you need attachments, upload them to your own storage and submit the URL as a text field.

## Spam protection

- **Honeypot**: set a **Honeypot Field Name** in the form's Setup tab (for example `_gotcha`) and add a hidden input with that name. Submissions that fill it get a normal success response but are not stored.
- **CAPTCHA**: Google reCAPTCHA (v2 and v3), hCaptcha, and Cloudflare Turnstile are supported. Send the widget's token in its usual field: `g-recaptcha-response`, `h-captcha-response`, or `cf-turnstile-response`. The endpoint picks the verifier from the field name (if both `h-captcha-response` and `g-recaptcha-response` arrive, as hCaptcha's widget sends, hCaptcha wins). Set the secret key with `PATCH /api/v1/forms/{id}` (`recaptchaSecret`). It isn't in the dashboard UI yet, and it must belong to the same provider as the widget. reCAPTCHA v3 tokens scoring below 0.5 are rejected. If the provider doesn't respond within 5 seconds, the submission is rejected. Tokens are removed before the submission is stored.

## CORS

By default any origin can submit. To restrict it, list origins under **Allowed Origins** in the form's Setup tab. Requests from other origins get `403`.

The check only runs when the request sends an `Origin` header, which browsers do. Requests without one (curl, server-side code) skip it, so allowed origins stop other websites from posting to your form but aren't authentication.

## Rate limiting

Default: **10 requests per minute** per IP, per form. You can change it with `PATCH /api/v1/forms/{id}` (`rateLimit`, 1 to 1000). It isn't in the dashboard UI yet.

When rate limited, the response includes a `Retry-After` header with the seconds until the limit resets.

The counter is kept in memory on each server instance. On serverless hosting like osforms.com, requests can land on different instances, so treat the limit as best-effort rather than an exact cap.

## Monthly limit

Each account can store 100 submissions per month (UTC calendar month). Past that, the endpoint returns `403` until the 1st.
