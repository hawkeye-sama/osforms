## 1. Create an account

Sign up at [osforms.com](https://osforms.com/signup). You'll get a 6-digit code by email. Enter it to verify your account.

## 2. Complete onboarding

Onboarding walks you through five steps:

1. **About You**: name, website, company, role
2. **Create Form**: your first form and its endpoint
3. **Connect Resend**: optional email notifications
4. **Google Sheets**: optional spreadsheet sync
5. **Implementation**: copy a code sample and send a test submission

You can skip the optional steps and set them up later.

## 3. Get your endpoint

Every form has a unique endpoint URL, shown in the form's **Setup** tab. Create more forms from the dashboard with **New Form**.

```
https://osforms.com/api/v1/f/abc123def456
```

The last part (`abc123def456`) is the form's slug.

## 4. Point your HTML form at the endpoint

```html
<form action="https://osforms.com/api/v1/f/abc123def456" method="POST">
  <input type="text" name="name" placeholder="Name" required />
  <input type="email" name="email" placeholder="Email" required />
  <textarea name="message" placeholder="Message"></textarea>
  <button type="submit">Send</button>
</form>
```

Set a **Redirect URL** in the Setup tab to send people to your own thank-you page. Without one, the endpoint responds with JSON: `{ "success": true, "message": "Submission received" }`.

## 6. (Optional) Use the React SDK

The SDK renders forms you design in the form's **Builder** tab:

```bash
npm install @osforms/react
```

```tsx
import { OSForm } from '@osforms/react';

export default function ContactPage() {
  return (
    <OSForm
      formId="abc123def456"
      mode="conversational"
      fullScreen
      onComplete={() => console.log('submitted!')}
    />
  );
}
```

`formId` is the form's slug. The form needs a schema saved in the Builder tab; a form without one renders nothing.

## 7. (Optional) Pull submissions into your platform

Create an API key in **Settings → API Keys** and read submissions from your server. See [Pull Submissions](/docs/api-reference/pull-submissions).
