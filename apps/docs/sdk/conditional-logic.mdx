Conditional logic is evaluated automatically by `@osforms/react` as the user fills out the form. Hidden fields are skipped in navigation and excluded from the submission payload.

## Types

Only `ConditionalLogic` is exported. Derive the other two types from it:

```ts
import type { ConditionalLogic } from '@osforms/react';

type Condition = ConditionalLogic['conditions'][number];
type ConditionOperator = Condition['operator'];
```

The shapes:

```ts
type ConditionOperator =
  | 'equals'
  | 'not_equals'
  | 'contains'
  | 'not_contains'
  | 'greater_than'
  | 'less_than'
  | 'is_empty'
  | 'is_not_empty';

interface Condition {
  fieldId: string;
  operator: ConditionOperator;
  value?: string | number; // not needed for is_empty / is_not_empty
}

interface ConditionalLogic {
  action: 'show' | 'hide';
  match: 'all' | 'any'; // AND vs OR
  conditions: Condition[];
}
```

## Usage in FormField

```ts
import type { FormField } from '@osforms/react';

const followUpField: FormField = {
  id: 'feedback_details',
  type: 'textarea',
  label: 'Tell us more',
  required: false,
  conditionalLogic: {
    action: 'show',
    match: 'all',
    conditions: [{ fieldId: 'rating', operator: 'less_than', value: 3 }],
  },
};
```

## How the SDK evaluates conditions

Conditions are re-evaluated on every answer. The evaluation helpers are internal; use `actions.visibleFields` from `useFormState` to read the result.

**Evaluation rules**:

- `equals` / `not_equals`: string comparison after `String(value)`
- `contains` / `not_contains`: substring check on the stringified value. For checkboxes (an array of values) this checks the comma-joined list, so use `contains` rather than `equals`
- `greater_than` / `less_than`: numeric comparison after `Number()`
- `is_empty`: `undefined`, `null`, or `""`. An empty checkbox array (`[]`) does **not** count as empty
- `is_not_empty`: any other value
- `match: 'all'`: every condition must be true (AND)
- `match: 'any'`: at least one condition must be true (OR)

## Accessing visible fields

When using `useFormState` directly, `visibleFields` reflects the current set of visible fields after applying all conditional logic:

```tsx
import { useFormState, useFormSchema } from '@osforms/react';

function MyForm({ slug }: { slug: string }) {
  const { schema } = useFormSchema(slug);
  const [state, actions] = useFormState(
    schema,
    `https://osforms.com/api/v1/f/${slug}`
  );

  // actions.visibleFields: fields visible for the current answers
  // actions.currentField: the field at state.currentIndex
  return <p>{actions.visibleFields.length} questions</p>;
}
```

Hidden fields are automatically filtered out of `visibleFields` and are not included in the submission payload.
