## Requirements

- `react` and `react-dom` 18 or later (peer dependencies)

## Install

<CodeGroup>
```bash npm
npm install @osforms/react
```

```bash pnpm
pnpm add @osforms/react
```

```bash yarn
yarn add @osforms/react
```

</CodeGroup>

## TypeScript

Types are bundled, so no separate `@types` package is needed. Import them from `@osforms/react`:

```ts
import type {
  FormSchema,
  FormField,
  FormTheme,
  FieldType,
  ConditionalLogic,
} from '@osforms/react';
```

Also exported: `FieldConfig`, `FieldOption`, `FieldValidation`, `FormMode`, `WelcomeScreen`, `ThankYouScreen`, `OSFormProps`, `FormState`, and `FormStateActions`.

## Next.js (App Router)

Works out of the box. Add `'use client'` when using in a Server Component file:

```tsx
'use client';

import { OSForm } from '@osforms/react';

export default function ContactPage() {
  return <OSForm formId="abc123" mode="conversational" fullScreen />;
}
```

## Next.js (Pages Router)

No special configuration needed, and no `'use client'` directive:

```tsx
import { OSForm } from '@osforms/react';

export default function ContactPage() {
  return <OSForm formId="abc123" />;
}
```

## Vite / CRA

Works without additional configuration.
