## Setup

1. Open your form in the dashboard and go to the **Integrations** tab
2. Choose **Webhook**
3. Enter your endpoint URL
4. Optionally enter a **Signing Secret**: any random string you choose. Store the same value on your server to verify requests
5. Save

## Request format

OSForms sends a `POST` request with `Content-Type: application/json` and `User-Agent: osforms-Webhook/1.0`:

```json
{
  "event": "form.submission",
  "formId": "64f1a2b3c4d5e6f7a8b9c0d2",
  "formName": "Contact Form",
  "submissionId": "64f1a2b3c4d5e6f7a8b9c0d1",
  "submittedAt": "2026-10-02T12:00:00.000Z",
  "data": {
    "name": "Jane Smith",
    "email": "jane@example.com",
    "message": "Hello!"
  }
}
```

`data` holds exactly what was submitted. Keys are your input `name` attributes (HTML forms) or field IDs (forms built with the form builder or `@osforms/react`).

Through the [API](/docs/api-reference/integrations#webhook-config) you can also switch the method to `PUT` or `PATCH` and add custom headers, such as an `Authorization` header for your endpoint.

## Verifying signatures

When a signing secret is set, every request includes an `X-osforms-Signature` header. Its value is the lowercase hex HMAC-SHA256 of the raw request body, keyed with your secret. There is no `sha256=` prefix.

```
X-osforms-Signature: 5d41402abc4b2a76b9719d911017c592...
```

Verify it against the **raw** body before parsing the JSON:

```ts
import crypto from 'crypto';

function verifySignature(rawBody: string, signature: string, secret: string) {
  const expected = crypto
    .createHmac('sha256', secret)
    .update(rawBody)
    .digest('hex');

  const a = Buffer.from(signature);
  const b = Buffer.from(expected);
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}

// Express example
app.post('/webhook', express.raw({ type: 'application/json' }), (req, res) => {
  const sig = req.header('x-osforms-signature') ?? '';
  if (!verifySignature(req.body.toString(), sig, process.env.WEBHOOK_SECRET!)) {
    return res.status(401).json({ error: 'Invalid signature' });
  }
  const payload = JSON.parse(req.body.toString());
  // Process payload.data...
  res.json({ ok: true });
});
```

<Warning>
  Verify the signature before processing a webhook, and compare with
  `timingSafeEqual` to avoid timing attacks. Without a signing secret, requests
  are unsigned and anyone who knows your URL can send fake submissions.
</Warning>

## Retry behavior

Webhooks are not retried. If your endpoint returns a non-2xx status or times out:

- The delivery is logged as failed for that submission
- You get an in-app notification and an email alert
- You can see the error in the submission's integration logs in the dashboard

Missed a delivery? Fetch the submission with the [Pull Submissions](/docs/api-reference/pull-submissions) API.

## Timeout

Webhook requests time out after **30 seconds**. Respond quickly and do slow work after responding.

## Testing

Once the webhook is saved, use **Test Webhook** in its settings to send a sample payload to your endpoint and check your signature verification.
