description: 'Add each form submission as a new row in a Google Sheet'

## Setup

1. Open your form in the dashboard and go to the **Integrations** tab
2. Choose **Google Sheets**
3. Click **Connect with Google** and approve access

OSForms creates a new spreadsheet in your Google Drive named after the form (for example **"Contact Form Submissions"**) and writes to its `Sheet1` tab. The integration settings show the connected account and a link to the sheet.

OSForms only asks for the `drive.file` scope, so it can access the spreadsheets it creates and nothing else in your Drive.

## How columns work

On the first submission, OSForms writes a header row: `Submission ID`, `Submitted At`, then one column per submitted field.

| Submission ID | Submitted At             | name       | email            | message |
| ------------- | ------------------------ | ---------- | ---------------- | ------- |
| 64f1a...      | 2026-10-02T12:00:00.000Z | Jane Smith | jane@example.com | Hello!  |

When a later submission includes a field that has no column yet, that column is added to the end of the header row. Values are matched to columns by header text, so you can reorder columns freely. If you rename a header, the next submission adds a new column under the field's original name.

Column names are your input `name` attributes (HTML forms) or field IDs (forms built with the form builder or `@osforms/react`). Arrays and objects are written as JSON text.

## Failure handling

If a Sheets API call fails, the integration is logged as failed and you get an in-app notification and an email alert.

### Google access expired or was revoked

If the error says Google access expired or was revoked (Google's `invalid_grant`), OSForms can no longer use your Google sign-in. This happens when you remove OSForms' access in your Google account, or when the sign-in hasn't been used for a long time.

Open the form's **Integrations** tab, choose **Google Sheets**, and click **Reconnect**. Sign in with the Google account shown under **Connected Account**. New submissions keep going to the **same spreadsheet**.

Reconnect only works with the account that created the spreadsheet, because OSForms can only open sheets it created for that account. If you sign in with a different account, nothing changes and you're asked to use the original one.

Submissions received while the connection was broken are still stored in OSForms. Download them with **Export** if you need to add them to the sheet.

### Starting over with a new sheet

To use a new spreadsheet (or a different Google account), **Disconnect** the integration and click **Connect with Google** again. This creates a fresh spreadsheet. The old one stays in your Drive.
