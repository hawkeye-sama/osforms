# OSForms - Open Source Form Backend

> This file is kept for older crawlers. The canonical, always-current file is https://osforms.com/llms.txt (full blog corpus: https://osforms.com/llms-full.txt).

## Overview
OSForms is an open-source, bring-your-own-key (BYOK) form backend for developers.
Point your HTML form at an OSForms endpoint. OSForms stores each submission and routes it to your own integrations (Resend email, Google Sheets, webhooks) using your own API keys.

## Pricing
- Hosted service at https://osforms.com: 100 free submissions/month, no credit card required.
- Every integration is included on the free plan, because your own API keys power them. You pay only your provider (e.g. Resend).
- Open source (MIT) and self-hostable against your own MongoDB.

## Key Features
- Public submission endpoint: POST https://osforms.com/api/v1/f/{slug}
  - Accepts application/x-www-form-urlencoded, multipart/form-data, and application/json
  - JSON requests get { "success": true }; HTML form posts get a 303 redirect when the form has a redirect URL set
- Integrations: Resend email (with optional auto-reply to the submitter), Google Sheets (auto-creates missing columns), webhooks signed with HMAC-SHA256 (X-osforms-Signature header)
- Spam protection: configurable honeypot field, optional reCAPTCHA, hCaptcha, or Cloudflare Turnstile (your own keys), per-form rate limit
- CORS control per form (allowed origins)
- Dashboard: browse submissions, submission charts, CSV export
- Pull API: GET https://osforms.com/api/v1/submissions?formId={id-or-slug} with Authorization: Bearer osf_live_... (read-only keys scoped to selected forms, 60 requests/min per key, cursor pagination)
- React SDK: @osforms/react

Not supported: file uploads are not stored (multipart file fields are replaced with a placeholder string).

## Security
- Your integration API keys are encrypted at rest with AES-256-GCM
- JWT authentication in httpOnly cookies
- Pull API keys are stored as SHA-256 hashes and shown once

## Tech Stack
- Next.js 15 (App Router), MongoDB + Mongoose
- Email/password auth with OTP verification, bcrypt, JWT
- Tailwind CSS + shadcn/ui
